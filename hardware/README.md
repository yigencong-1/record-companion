# 硬件工程入口

当前没有定稿BOM、接线、原理图或PCB。候选比较、接口、电源预算和每轮试制规则见 [项目计划](../product/plan.md)；功能边界见 [整机规划](../product/README.md) 与各功能专项。

阶段主控按D063先用S3模块台架，成品以S31为主；不因采用S3开发板就冻结成品管脚、模组、电源或板形。S31主板在准确变体/模组、外围、供电及迁移验证输入到位后设计，预留的资源与接口以联合评审为准。

工程目标是一块集成主板，先在 `hardware/prototype/` 保存便于测量和返修的试验板，再在 `hardware/product/` 保存按声音、外壳和装配确定的成品板。每个版号应包含嘉立创可编辑源工程、原理图PDF、BOM、制造文件、封装/引脚核查和实际测试记录。

试验板与成品板的板形、尺寸和免费券条件分别管理；每轮只为解决明确问题改版。与 [mechanical](../mechanical/README.md) 共同审查音腔、固定、电池、天线、NFC距离、Type-C和维护路径。个人库存和采购记录不放入公开仓库。
