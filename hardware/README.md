# 硬件设计入口

当前已有[材料盘点表](inventory.md)，尚无定稿BOM、接线工程、原理图或PCB。具体器件按[开发流程](../docs/development-process.md)比较选择，功能边界以[功能规格](../docs/function-spec.md)为准。

候选报告建议放在selection/，记录必要能力、官方来源、价格及日期、外围与实现成本、推荐理由和对应功能编号。接线、接口、电源预算与BOM随实际模块和器件确认建立。

集成目标是一块主板。真实工程试验板保存到prototype/，成品板到product/，分别按板版号维护嘉立创源工程、原理图、BOM及制造文件。每次改版记录目标、修改依据、工艺及测试结果；免费券资格与试制条件按当期规则核对。

与[结构工程](../mechanical/README.md)共同审查接口、固定、音腔、电池、天线和维护空间。版号与固件、验证证据对应，制造文件不能代替可编辑源工程或实物验证。
