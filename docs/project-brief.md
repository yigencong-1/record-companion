# 项目简报

更新日期：2026-10-08。本文区分已确认要求、设计建议和待定事项，供协作者理解当前技术范围。

## 目标与已确认功能

制作一套可日常使用的通用音乐播放器、唱片桌搭与唱片挂件，支持离线播放和自行更新内容。

| 功能 | 已确认内容 |
|---|---|
| 桌面本体 | 通用本地音乐播放器，可独立播放并配合灯光；唱片转动是希望实现的效果，原型先验证播放与识别再验证运动 |
| 唱片挂件 | 可挂在书包上；放回本体时触发对应音乐或灯光场景；用户接受插入或表面放置 |
| 首批唱片 | 邓紫棋唱片、汪苏泷唱片和通用唱片；不同唱片对应不同歌曲 |
| 无唱片播放 | 本体不放唱片时也能播放，日常播放不以唱片在位为前提 |
| 手机网页 | 切歌、调音量与灯光、上传歌曲、绑定唱片与播放内容 |
| 生日入口 | 仅保留一张可配置的生日唱片和一个生日菜单入口；文字、歌曲和操作仍待设计，尚未实现 |
| 体量 | 整体不要太大；用户要求先看示意图，尚未选择具体厘米数 |
| 音质 | 保留D019的成品目标；先做模块，原型阶段能做好音质就先做好（D036），当前不设参考设备（D035）；成品听感仍需后续验收 |
| 下一版评估方向 | 左右扬声器与前屏，优先评估此前墨水屏桌搭的屏幕和显示逻辑；具体声道结构、实物屏型号和界面待验证 |
| 联网与配网 | 本阶段先连接外部Wi-Fi或手机热点，通过设备本地AP网页配置；无网仍能使用基础功能 |
| 电池与充电 | 内置较大容量电池，插入Type-C时可继续使用并充电；续航尽量长，容量与具体时长未确定 |
| 原理图与PCB | 平台先定嘉立创；具体EDA版本、器件和板层待原型后落实 |
| 原型路线 | 先面包板、洞洞板或现成模块逐块验证；经选型评审集成一块主板，利用适用免费打样迭代，再做成品PCB与外壳 |

“独立播放”表示平时不依赖手机持续连接。用户已提出内置电池与边充边用；具体续航尚未确定。
主要日常功能围绕本体和唱片互动；生日唱片与菜单使用同一本地内容管理机制。

AI日常问答属于新增功能探索。用户尚不清楚具体要做哪些功能，麦克风、语音唤醒、服务商与内置移动联网模块均未确定；无网时仍能使用基础桌搭与本地音乐功能。

唱片可绑定歌曲或歌单，具体内容通过后续选曲和网页设计落实。通用唱片对应全曲库、自选歌单或其他内容尚未决定。无唱片时的选曲入口、默认内容，以及播放中放入或取走唱片时的行为，需要在操作概念中审阅。
歌曲不必物理存储在小唱片内；歌曲存储和唱片识别方式尚未确定。

## 设计建议：尚待验证

- 挂件目前按不带电的小唱片饰品考虑，识别与具体互动方式待验证。
- 电源候选采用带电源路径管理的Type-C充电、成品保护电池与系统稳压，验证边充边用后再定正式电路。
- 按D036在模块验证中同步改善扬声器、音腔、功放与供电，由声音方案及实际模块反推紧凑外形；制造尺寸留到后续验证。
- 网络优先采用原型主控自带Wi-Fi落实D024；首次或手动进入AP网页设置兼容的外部网络，设备热点也可管理本地内容。内置蜂窝联网模块待用途明确后评估。
- 前屏优先核对旧墨水屏材料及驱动，日常显示时间、曲目和电量；原作品使用2.9英寸、296×128屏，用户实物是否匹配尚未确认。具体复用范围、刷新体验和AI用途待验证。
- 探索可爱与酷两种视觉方向，先审阅整体造型和操作。
- 生日唱片与菜单复用规划中的歌曲/歌单绑定机制；具体触发规则仍需审阅。
- 网页上传和绑定让使用者能自行更新内容。

以上建议不是已确认的电气参数或实现方案。

## 2026-10-08 继续规划

用户确认转动“能实现更好”，小唱片“插入还是在表面我也都可以”，见D017。主控据此推荐以水平唱片机与静止小唱片卡座继续规划：大唱片负责视觉转动，小唱片负责选择内容；先验证声音、网页和识别，再验证运动及噪声。

[下一步规划](next-stage-plan.md) 给出结构关系、操作草案和实验顺序，[材料盘点表](../hardware/inventory.md) 用于核对库存与工具。具体卡座形态、外观尺寸、配色、操作规则和转动机构仍依据审阅及原型结果收敛，不把主控建议记作用户已选定的细节。

用户随后要求整体不要太大，并强调“音质是肯定不能牺牲的”，见D018、D019。最新规划展示两档体量参照，推荐先验证较宽裕的一档与表面平放凹座；具体尺寸未经用户选择，也未通过声学和装配验证。第一轮小功放和扬声器仅是播放通路候选，不作为成品音质承诺。

同日新增方向见D020–D023：评估左右扬声器与前屏；内置电池、Type-C边充边用，续航尽量长；原理图与PCB平台为嘉立创；AI用途尚未确定。加入双音腔、屏幕和电池后，上一轮15厘米/12厘米图只作历史占地参照，尺寸和费用需重新评估，不沿用为整机装配或音质承诺。

随后明确本阶段通过本地AP网页配置外部Wi-Fi（D024），并提出沿用此前墨水屏项目，先评估材料及显示逻辑复用（D025）。原作品的屏幕和STM32驱动已核查，未复制源码；若采用ESP32-S3，需要移植底层并验证显示刷新与播放并发。用户授权使用gpt-image-2生成一张实体效果图（D026），[效果图](../assets/concepts/epaper-player-3d.png)已生成并查看。图中配色、格栅和凹座为探索，不代表用户已选定外观或完成结构、声学与续航验证。
