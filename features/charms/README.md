# 挂件外观、实体与材料专项

按D060独立规划八张圆形挂件的外观、材料、实体封装、挂扣、耐用性与小批制造。当前为P1方案比较，首轮具体方案由本专项交付；尚无批准尺寸、加工BOM、有效制造报价或样品验证。

## 已确认范围

八张配置依D057：邓紫棋、汪苏泷各一张，通用1–5各一张，生日0一张。各卡可用不同材质，多个完整外壳方案并行比较；两张歌手卡与生日0重点关注外观和耐用。生日仍只保留一张卡和一个菜单入口，不引入私人背景。

挂件采用无电池NFC或类似电磁感应身份（D058）。小挂件可在浅凹座平放或放入无需扣紧的插槽，最终承接方案未选；大唱片始终平放。挂件可作为书包挂件，标签层与承力结构分开考虑。

## 交付与事实入口

已记录的初轮材料候选及交接见[唱片专项](../records/README.md#挂件实体外壳与材料规划交接由总规划安排)，包含PC、PMMA、PVC/PETG夹层及PCB外观备选。此后挂件细规格和比较结论维护在本页，原比较保留作为来源，不同步维护两套细规格。

首轮应比较完整组合，不能只有效果图：正反面与可见编号、材料/牌号、层叠、直径/厚度/质量建议、边缘处理、印刷或覆层、标签固定与芯片让位、连接/封装、挂扣承力、卡座配合、加工渠道与小批费用。未知值标待核实，概念尺寸不作制造定稿。

建议收敛两至三套有不同用途的候选，分别说明适合哪类卡；对八张卡给出共同视觉体系及三张主题卡的方向。每套给出样片制作与外观审阅方法，以及跌落、刮擦、挂耳拉力、分层、图案耐久和封装后识别的验证计划。费用注明日期、数量档、打样/印刷/封装是否包含、最小起订量和交期，未询得报价时不编造价格。
