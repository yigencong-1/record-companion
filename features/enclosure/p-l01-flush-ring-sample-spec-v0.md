## 1. P-L01 测什么、不测什么

**本样件只检验两件可见外观件的交界：木纹视觉顶板与非导电圆形低环**。重点是：
- 装好后的视觉齐平、阴影接缝是否连贯、同一环周是否出现明显不均匀。
- 饰膜/木皮开孔收边是否整齐、是否因装环、拆环而翘边、破裂或积胶。
- 拆装是否从背面完成且不拉动饰面、不依靠贴膜受力；打印/切割/喷涂公差实际影响有多大。

**不包含**转盘电机、扬声器、密闭音腔、真实天线、NFC 标签 B 模式离座测试、电源或完整手机网页。为做外观可放一张无电子身份的**尺寸替身圆片**，必须标“惰性样片”；它不能成为第九张正式 NFC 卡，也不能代替蛋糕异形卡的全包络验证。

## 2. 两条加工路径：相同齐平低环，工艺不同

| 路径 | 可以交给加工方制作的结构意向 | 优点 | 风险／本轮推荐 |
|---|---|---|---|
| **P-L01-A：贯通孔＋等宽阴影缝（优先）** | 平整板材先完成真实圆孔并去毛刺；在板面贴木纹饰膜并对孔边精确修整；独立外环从下侧的安装座定位，环外缘与孔边之间保留可观察的均匀细缝，环高度由背后支撑与垫片调整 | 激光/平板切割＋普通打印件即可初步试验；方便记录真实尺寸与返工 | 饰膜裁切边暴露，容易出现局部毛刺／误差；**首轮只作为最低复杂度的可行性样件** |
| **P-L01-B：隐蔽贴膜切口的台阶收边（条件备选）** | 在分层板材或独立遮边件上做错层盖边，使饰膜的裁切口藏在环下；底层仍是可拆承力座，环最终可见表面保持低环 | 视觉上更容忍膜边的小偏差，边缘不容易直接被手触到 | 可能需要双层板/局部开台阶/CNC 或第二道粘接；不能把“遮住了”理解成已解决附着差或音腔干涉 |

两种路径都**不能**把圆环直接粘在饰膜上承力，也不为了遮边让外圈明显高起；实物低环表面允许可控高差与细阴影线，最终优选由样品而非渲染决定。

### 推荐的首轮顺序

先请加工方评估 **A 路径**的工艺能力并做局部切口/可拆试片；若孔边起翘、毛边很难修正，才追加 **B 路径**的局部结构试片。两个都不预设为量产方案，优先利用加工商已擅长的切割与修整工艺，不为了“无缝”强制增加昂贵复杂曲面加工。

## 3. 参数化尺寸字典——真实毫米值全部待输入

选择同一个局部安装基准（`z=0`：背面固定座的参考安装平面）；圆环和顶板都相对于这一平面定位。

| 变量 | 含义／计算关系 | 当前状态及来源 |
|---|---|---|
| `D_tag_max` | 八张实体挂件中最大实际平面轮廓；生日卡另给局部支撑弧 | **UNKNOWN**；历史45–55 mm是候选区间，不是已确认最外径 |
| `D_ant_env` | 真实天线+固定与连接线的包络 | **UNKNOWN**；此前PN7160的25×10、50×40 mm只是套件候选线圈实体，不等于最终圆台净空 |
| `D_ring_o, D_ring_i` | 非金属环外/内径；可见宽度 `w=(D_ring_o-D_ring_i)/2` | **UNKNOWN**；不得照搬72 mm示例 |
| `D_hole_finished` | 贴膜开孔和修边后可供环进入的完成孔径 | 由试板几何/膜裁切和工艺共同确定，不等于激光原始孔径 |
| `D_ring_finished` | 喷涂/磨光后的外环实际外径 | 厂商印刷、喷涂与尺寸测量结果 |
| `g_radial` | 名义径向视觉缝 `(D_hole_finished-D_ring_finished)/2` | **比较参数**，不是先定公差；同心定位误差会使最窄处更小 |
| `t_panel, t_film, t_ring` | 板材实体、实际饰面胶膜、后处理后的装饰环高度 | 实物试片或厂商承认的加工数据；不可直接取渲染厚度 |
| `h_carrier, h_shim` | 支撑座定位面相对 `z=0` 的高度与可调垫片组合 | 参数化，不冻结卡扣/螺钉形式和垫片厚度 |
| `delta_z` | 装好后 `环顶面 z_ring - 饰面完成顶面 z_panel` | **视觉目标近 0**，不要求绝对零；拍照与四方位高度量测 |
| `L_coupon, M_edge` | 试片外形与孔外的夹持/修边/固定余量 | `L_coupon >= D_hole_finished + 2 M_edge`，数值由外包工艺与试样测试需要反推 |

如外环确实从完成孔径内定位且使用普通间隙配合：`g_radial>0` 才有自由落入可能；还需检查 `g_min = ((D_hole_nom - tol_h) - (D_ring_nom + tol_r))/2`，确保在实际公差和涂装后没有干涉。厂家对切孔、成品环的几何误差及环心偏差都需要记录，不能照搬通用“FDM精度”当厂商保证。

**装配高度尺寸链**（同一背面安装基准）：
- `z_panel = h_panel_seat + t_panel + t_film`
- `z_ring = h_carrier + h_shim + t_ring`（其中 `t_ring` 计入实际表面涂层）
- `delta_z = z_ring - z_panel`

其中 `h_panel_seat` 是基板在背面托架上的定位面高度；它与 `h_carrier` 可能不同。不要通过压紧饰膜来补偿 `delta_z`，应使用可替换定位片／重新改支撑台阶。

### 3.1 试样敏感性设计（测试档位不是定稿尺寸）

在同一完成环件上**依厂商实际加工能力**设置可换背面垫片/高度位置，使它分别略低于、接近、略高于木纹饰面；在四个方位记录 `delta_z` 并用斜光摄影对比。**此时不规定 0.2/0.5 mm 等固定容差**：先询加工商成品公差、涂层厚度和板材偏差后才定义测试档位。必要时用同一底座对比两种孔边加工方案，不为每种方案直接外包整机大壳。

## 4. 具体外包分件与制作顺序（局部试样，不是完整外壳）

| 子件代号 | 第一轮候选加工方式 | 必须注明的图纸/验收信息 |
|---|---|---|
| P01-A 木纹面板小试片 | 平整亚克力或其他经过胶膜相容性审核的平板基材；先加工孔、修边，再贴膜裁切；B路径可改为复合层 | 成品孔、真实膜厚、木纹方向、可见面和背面、裁切顺序与试样批次 |
| P01-B 非金属齐平低环 | 小批 3D 打印并表面填补/打磨／哑光暖色涂装；必要时比较未喷涂的树脂/板材环 | 装完后的外径与高度，重点上表面质量，不使用金属粉漆/电镀层靠近未来天线区 |
| P01-C 可拆承力/高度调整座 | 结构打印件或两片平整基板叠合，定位与可替换垫片；底面取下环而不拉膜边 | 装配界面、力的传递、拆卸工具入口和不穿透音腔边界的方案说明 |
| P01-D 可选惰性外观片 | 无芯片、非 NFC 的普通圆片，只检验视觉是否凸出及指尖取片趋势 | 明确标无电子功能、非生日正式挂件，不据此申报实际手感/读区通过 |

**推荐制作顺序**：
1. 先取得厂商的板材和装饰膜试片，确认木纹/颜色、可见面和加工设备限制。
2. 做普通圆孔板、非金属环、背面定位座；各件测原尺寸，记录修边/喷涂前后。
3. 将木纹膜贴合于清洁、适用的平整基板，修整孔边；不把膜大幅拉伸包覆复杂圆孔立壁。
4. 将独立环从对应定位面装入并调整高度，靠独立支架定位；默认**优先研究背面可拆紧固**，不要求首样采用易断卡扣或金属螺钉。
5. 拍摄自然光/斜光特写并测缝/测高；反复拆装、再次观察饰膜边缘。若边缘不理想，启动B路径而非继续用胶强拉遮盖。

### 4.1 制作工艺依据与注意边界

- 3M DI-NOC《Installation Guide》2026-02 Rev M：平整基材通常更有利于贴合；Acrylic/PETG 等基材有相应测试资料；接缝、边缘及工件周围的粘接行为可能受基层与施工影响。原始安装指南：<https://multimedia.3m.com/mws/media/1576574O/di-noc-install-guide-rk-pdf.pdf>。
- Protolabs 工业 3D 打印指南将特征尺寸、最小间隙、构建体积和不可处理部位按工艺分类，**不提供任何一家国内小批外包商本项目的保证公差**：<https://www.protolabs.com/resources/design-for-3d-printing-toolkit/>。
- 如果最终选用其他品牌的木纹膜/喷漆，需重新核实对应厂商的基材附着、温度和后处理条件，不照搬 3M 料号和工业大卷采购成本。
