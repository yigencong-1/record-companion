## 1. 设计目标与现行约束

主方向：**低矮横向一体式桌搭＋顶部水平大唱片＋前向左右双声道＋前置墨水屏与可换控件区＋独立静止的小挂件座**。工业设计方案名称“方案 A”**不等同于**结构专项的“小卡平放浅座 A”，也不等同于产品的 A/B/C 播放行为。

- **已确认**：大唱片平放（D056）；整体紧凑但不牺牲音质（D018/D019）；阶段路线为 S3 模块验证／S31 成品主线（D063）；音质与性价比两条声学路线都按约 1 米条件比较（D064）；实体控件数量及映射未冻结（D070）；完整在途测试工程先留本机（D086）。
- **已有偏向**：材料外观从 3D 打印框架／安装件＋亚克力平板入手；唱片外缘下方的**固定柔光圈**作为主要灯位，发光位置已得到用户偏向，但颜色、功率、效果、灯数尚未定稿。
- **必须保留比较**：小挂件可换“平放浅座”和“自然落座浅槽”；完整裸单元独立音腔与带壳音频组件各走同口径验证，不因外观压缩掉声学路线。
- **尚未决定**：盘径、外壳尺寸、卡座的准确坐标／安装形式、控制器件数量、Type-C具体位置、传动与电池型号、精确音腔容积和结构公差。

## 2. 首版功能分区（非比例图）

| 视角／区域 | 方案 A v0.1 布局建议 | 不能越过的边界 |
|---|---|---|
| 正面左／右 | 两侧各一处前向扬声器格栅，对应各自独立封闭音腔 | 格栅与单元同侧朝前；内部不混放电池、主板、电机或卡座 |
| 正面中央 | 前置墨水屏可视窗口＋**可换控件区** | 不以效果图的旋钮／两键冻结真实数量；FPC、屏幕禁压边必须留净空 |
| 顶部中央 | 水平大唱片、承载盘、独立轴承／轴向定位；下方固定柔光圈 | 电机负责传扭、不默认承盘重；旋转扫掠区包含偏心、跳动与工差 |
| 顶部静止区 | NFC 小挂件承接座先试右后侧固定边沿；浅座／浅槽共用可换接口 | 不随大盘旋转；挂扣、软带、手指取放都不得扫入转盘；读区需隔离金属与动态件 |
| 中央骨架 | 上层可拆运动支撑；其下或旁侧安排控制板、储存与信号线 | 轴承承力不得交给屏框或薄亚克力顶板；电子层不得借用音腔 |
| 中央低位 | 电池及其独立固定与保护空间 | 不预先假设电池和 PCB 能安全叠放；需可检查、可拆取并有热边界 |
| 机身背／底 | 优先比较中央后盖维护，底盖为对照；固定 USB、存储、烧录恢复路径 | 换电池／存储、调试、拆运动件尽量不破坏音腔密封或先拆屏幕；接口与线头须有应力释放 |

### 2.1 位置备选，只是为了第一轮比较

- **A1（优先验证的概念）**：大盘轴心近整体横向中线，前面两侧对称声学布局；小挂件座暂放顶部右后**静止边沿**。优点是正面更均衡；风险是右后挂扣／手指与转盘扫掠、外壳顶板宽度、天线金属环境冲突。
- **A2（碰撞时的备选）**：主盘和正面声学布局不变，挂件座改为机身侧缘的一块独立固定可换座。优点是更容易与旋转区分开；代价是左右外包络可能增大，电缆／天线、桌面摆放和防倾倒须重新审查。
- 两者不预先确定“浅座还是浅槽”。挂件座的最终位置**不由概念图认定通过**，必须等盘、标签、天线、挂扣和取放手部包络齐备。

## 4. 尺寸反推方法：先包络，后尺寸

先索取各专项给出的**准确版号与完整运行／拆装包络**。用于审阅的最小尺寸受以下约束共同控制：

- 宽度：左音腔外包络＋中央结构宽度＋右音腔外包络，**再与**盘／固定卡座的横向联合包络取较大者（含隔板与必要边界）。
- 深度：大盘前后扫掠空间、前部显示／操作区、背部 USB／维修接线空间的联合边界；不能只取大盘直径。
- 高度：声学单元深度、中央转轴／传动／柔光圈叠层、电池和底脚、挂件露出高度共同约束；允许不同区域有不同局部高度。
- 每侧净音腔量应扣除实际单元、支撑、密封等排量，不能从外壳长宽高直接认定；当前 0.5/0.8/1.0 L 属结构／声音台架的候选档位，**不是定稿尺寸**。

## 6. 此刻不登记为正式产品决定的问题

1. 更倾向大盘视觉严格居中，还是允许为静止卡座留空间而轻度偏置？
2. 静止挂件座愿意先试机身右后边沿，还是更愿意试侧边独立耳座？
3. 前置墨水屏优先居中，还是在保留双前向音腔的前提下可略偏以增加控件空间？

这些是需要通过外观布局和包络核查再共同选择的**候选取舍**。未获确认前不新增 D 号，不修改固定的 ABC 播放语义或采购、BOM 与硬件平台路线。
