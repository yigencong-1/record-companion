## 1. 模型对象与重要排除项

这次建的是一小块 **P-L01-A 贯通孔＋均匀阴影缝**外观工艺试板，不是整机右后圆台，不是完整挂件座。它的作用是试验板上可见环缝和齐平高度，方便以后委托板材切割/3D 打印。

**包括 5 件**：试板基材、作为木纹膜可视化占位的薄层、非金属环、可选垫片、**仅用于位置演示**的背面环形定位座。

**不包括**：真实 NFC 天线/接口、卡片承载／防脱机构、S1/S2 托芯几何、右音腔、盘电机及承力、供电与设备主板。当前后置定位座**没有设计固定到试板的螺钉/卡扣**，必须待 CAD 结构深化；不能因部件在渲染中对齐就认为是可抓起的独立实体装配。

## 2. 首轮可运行的示例参数（单位 mm，全为自定试验值）

| 变量 | 示例工作值 | 含义与状态 |
|---|---:|---|
| `L_coupon` | 130 × 130 | 工艺小试板的外形，**不是机身尺寸** |
| `r_corner` | 6 | 仅试板圆角 |
| `t_panel` | 3.00 | 待测试的板材名义厚度 |
| `t_film_proxy` | 0.20 | 虚拟木纹饰面/胶层总厚，**没有实物测量** |
| `D_ring_finished` | 84.00 | 非金属环的**名义完成外径**，**不是成品圆台尺寸** |
| `D_ring_inner` | 68.00 | 内孔直径，仅供观察圆环视觉宽度，**不证明能放挂件/天线** |
| `t_ring_finished` | 2.40 | 环名义完成高度，未考虑真实涂装偏差 |
| `g_radial` | 0.50/侧 | 设想的径向可见阴影缝，**不是获得厂商保证的公差** |
| `D_hole_finished` | 85.00 | 由 `84+2×0.5` 推导，指修边/饰膜后**完成孔径** |
| `h_shelf` | 0.50 | 背面支撑台阶高出试板底面的工作值 |
| `h_shim` | 0.30 | 名义齐平的垫片状态；另试 0 与 0.60 |
| `D_carrier_base` | 108.0 | 下方环形演示支撑体外径，不是最终安装座设计 |

衍生结果：
- 环的可见径向宽度 `(84−68)/2=8.0 mm`；
- 试板孔边到正方形外缘（轴向最短）的名义边宽 `(130−85)/2=22.5 mm`；
- 饰面顶面 `z_panel=3.00+0.20=3.20 mm`；
- 环顶面 `z_ring=0.50+0.30+2.40=3.20 mm`；
- 名义高差 `delta_z=z_ring−z_panel=0.00 mm`。
- 用相同底座比较 `h_shim=0 / 0.30 / 0.60` 时，环顶相对饰面名义 `delta_z=-0.30 / 0 / +0.30 mm`，只研究视觉趋势和可调范围，不规定量产允许值。

**首轮参数不是公差规格**。如果 3D 打印、切孔和喷涂的实际结果偏离名义值，细缝可以局部变窄或环面高低不均；必须用厂商可保证的数据和实物替代本表。

## 3. 需要逐步替换的真实输入

| 对接人/专项 | 需要补到参数表的真实资料 | 不提供则无法确认 |
|---|---|---|
| 加工厂 / CMF | 准确板材种类与厚度分布、木纹膜/胶厚、成品孔精度、环成型和后处理偏差 | 最终环缝及齐平公差、加工价格 |
| NFC 与挂件 | 八张卡最大外廓、生日异形卡/孔区/扣具真实厚度、实际天线+接头/读区 | `D_ring_inner`和实际圆台外径是否能承接 |
| 结构 / 音频 | 右侧音腔完整密封边界、中央后部支撑桥架、拆卸方向 | 圆环后部能否有可靠不穿腔的固定 |
| 运动 | 大唱片实际扫掠直径/跳动、指尖取放的动态范围 | 圆台右后位置能否避开盘边与取放 |
| 平台 / 电源 | 真实 S31 成品 PCB、天线禁区、接口线头和电池包 | 实际机身高度与后盖维修空间 |

**注意**：原来 72 mm 圆台只是另一轮几何演示；这里使用 84 mm 试样环外径是为了研究拼缝，不代表已将展示台增加到 84 mm。也不能通过 68 mm 内孔简单推断 50×40 mm 天线或 55 mm 卡片真正能装下（尚缺连接器、角度、RF 金属环境、抓取与夹持区域）。

## 4. 这次实际执行到什么程度

本轮在工作容器中使用 **CadQuery 2.8** 生成参数化示例：
- `p_l01_parameters.json` 统一维护工作值；`p_l01_cadquery.py` 负责重新生成几何。
- 输出总装 STEP、五个零件 STEP、相应 STL、二维基板参考 DXF、参数计算报告、实际几何渲染 PNG。
- 校核 CAD 中 **5 个单件均是有效实体**；对示例零件做交集，**未检测出正体积互相侵入**。这仅证明该示例几何一致，不证明真实喷涂、贴膜、固定或使用功能通过。
- **没有设计板与背面定位件之间的最终结构紧固**，不具备实物搬动、防脱或长期耐用性结论。
- STEP 可以让 SolidWorks 导入、测量和二次建模，但**不附带 SolidWorks 原生特征树**；Python/CadQuery 与 JSON 是当前保持参数化可修改的源。
- 输出模型在当前聊天交付的 ZIP 包中，仓库只提交参数规划与事实核查记录。无厂家 RFQ、无打印/切割/贴膜样件、无实物 NFC/音质测试，QA 项目保持 NOT RUN。

## 5. 进入下一步前的门槛

**P-L01 v0.1 数值演示可供审阅，不可直接下单。**

进一步的参数化样件开发应先：
1. 将实际板厚、膜厚、打印／涂装后的环外径偏差与孔修边偏差加入参数集，生成至少低/平/高三档装配对照；
2. 选定适用于真正试板的**背面可拆定位和防脱机构**，再校核紧固件是否露在可见面，避免损伤饰膜；
3. 按厂商加工能力设置后续可检验的环缝/高度判据，样件制作后分别记录几何尺寸与视觉效果；
4. P-L02 托芯、P-L03 NFC 与 P-L04 支撑桥架的测试不得由 P-L01 小试片代替；保留 Q/V 两条声学路线，继续八张 NFC 卡及生日蛋糕卡决定。

**本轮不冻结成品尺寸、PCB、部件或成本，不修改 `main`，不创建 PR。**
