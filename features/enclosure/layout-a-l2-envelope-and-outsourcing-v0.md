## 一、这一轮可以确定的工程方向

**保留外观，重组内部**：暖白外部装饰壳与胡桃木纹平顶板负责观感；顶部唱片的质量走**独立轴承＋中央承力安装板**；左右各自独立的声学模块负责音质；电子和可拆电池放在中央维护区。挂件座采用静止的可换结构，优先核对顶部右后边沿，不得破坏右音腔或进入唱片扫掠区。固定暖白柔光圈置于唱片外缘下方，与大盘运动件分开。外露旋钮／按钮只代表未冻结的可换控件位。

**正面与顶部视觉控制**：大盘轴心优先在整机横向视觉中线上，左、右前向扬声器中心相对于该线镜像；前屏有效区优先中置。这里是**造型目标**，不假设隐藏结构必须镜像，不卡死屏幕和实体控件数量。

**两条声学路线并行**：
- **Q 路线（音质对照）**：两只 Peerless PLS-P830985 进入各自可调密闭音腔；先用可拆试箱对照单侧净容积 0.5／0.8／1.0 L，不将整个箱体外围长宽高当成净容积；外观需容纳其可能更大的声学空间。
- **V 路线（性价比对照）**：保留 Waveshare 8Ω／5W 带壳组件的原始声学外壳，整套组件作为另一套模块；不要额外套上一个未验证的密闭箱后声称是同一个声学条件。
- 两路线都要按 D064 测试，且**不强制两者共享一套最终成品外壳**。可以共享视觉语言、前面板布局和连接接口，但若声腔结构根本不同，允许有不同内部支架甚至不同深度的试验壳，再用声音／体量／费用证据选择。当前并不批准哪条路线或最终声学配置。

## 三、用真实参数反推尺寸，而不是采用生图标出来的数字

### 3.1 首个 CAD 坐标约定

- \`x\` 左→右，\`y\` 前→后，\`z\` 底→顶；外轮廓 \`W×D×H\` 皆**待求**。
- 横向中心 \`x=W/2\`。目标 \`x_disc=x_screen=W/2\`，\`x_speaker_L+x_speaker_R=W\`。后者不代表单元和卡座必须相同形状。
- 大盘动态半径：\`R_swept = R_disc + eccentricity + runout + assembly_allowance\`；以上每个实物量都暂缺。其扫掠圆柱不能与**小挂件／扣具／手部取放活动范围**相交。
- 顶板平面可与侧音腔的上方投影重合，但任何卡座固定柱、螺钉、走线或开槽**不能未经验证穿透密闭腔壁**。视觉层重合≠结构容积可以被重复占用。
- 整机最小外宽要容纳 \`左声学实体包络＋中央骨架包络＋右声学实体包络＋必要隔离/维护\`；还要与大盘动态横向包络和固定卡座的联合占位取更大者。深、高也用实体包络、叠层及维护净空算，**不能只将图片里的 W/D/H 当尺寸**。

### 3.2 音腔体积必须计算排量

\`V_net = V_geom_internal - V_speaker_displacement - V_brace - V_seal_features - V_internal_parts\`，按毫米计算后除 \`1,000,000\` 转升；这里的支撑凸台等体积不允许与外壁重算。

**只为理解方法的假设算例（不是本项目尺寸）**：单侧内空长宽高取 100×150×85 mm，则原始几何容积为 **1.275 L**。如希望单侧净容积 1.0 L，单元背部、支架、填块等所有内部排量**最多只能合计 0.275 L**；若目标 0.8 L，可允许合计不超过 0.475 L。真实箱体还须有连续密封面、外壁、阻尼与可拆后壁。因此仅凭效果图的低矮感无法保证完成 1.0 L/侧。

**不可用整机总容积大于2L**就宣称两个1L密闭腔可以装入：受前向单元外框、中央骨架、防干涉和空气密封约束，必须完成分腔几何验算。

## 五、针对小批外包的分件与装配顺序

| 加工/装配组 | 零件职责 | 外包技术路线（初选） |
|---|---|---|
| **F1 前脸装饰板＋主外框** | 奶油白连续可见曲面、前屏窗口、左右格栅开口、可换控件小面板 | 小批 FDM 分件打印＋补土／打磨／底漆＋哑光面漆，实际划分随打印体积与良率调整 |
| **F2 顶部装饰板** | 胡桃木视觉平板、真实开孔及边沿阴影缝 | 亚克力／其他平整板材切割＋木纹饰膜；**装饰板不承载大盘轴承** |
| **F3 左右声学件** | 保留两只各自封闭的气密音腔、前障板、网罩独立更换 | 分别做 Q 路线可调试箱和 V 路线原壳适配框；外观与真实音响量测分开 |
| **F4 中央承力件** | 转盘独立轴承、电机／联轴、上部灯槽、PCB／电池固定点 | 结构打印件与标准轴／轴承／螺纹件组合；刚度／隔振及装配精度之后验证 |
| **F5 灯槽＋固定扩散件** | 隐藏 LED 颗粒、控制漏光、允许更换 | 小段弧槽先打样，再根据盘径生成整圈；无电线接到旋转盘上 |
| **F6 卡座适配件** | 同一区域比较平放浅座 S1 和自然落座槽 S2，独立读卡天线方向 | 单独小件打印；不穿过声腔、不让扣具进入盘运动区 |
| **F7 底／后盖** | 可拆 SD／电池、恢复与 USB 接口可达、整机稳定站立 | 分件打印或切割件；优先中央后部维修，底部维护保留对照 |

**建议的 CAD 总装顺序**：中央骨架 → 两套独立声学包络 → 动盘承力／电机／光环 → 电池与电子包络 → 前屏／控件开窗 → 胡桃木外观板 → 挂件及手部动态包络 → USB/SD/维修盖。任何完成度都须注明“概念几何／资料尺寸／实际样件／测试”，不能把经过布尔无干涉运算的空箱写为已验证实物。

## 六、这轮判断的阻塞与交付门槛

**L2-P0 最优先收集五类准确输入**（不必等所有硬件采购）：

1. 大唱片与承载盘的候选直径、质量范围、轴承支撑＋电机整套高度，含灯槽和可拆操作；否则**总深、高与右后卡座不能求解**。
2. Peerless 完整厂家版机械图、实体安装余量和每侧0.5/0.8/1.0 L试箱的结构容积；同步保留 Waveshare 原壳整体外形。
3. 前墨水屏实际型号、外框、有效区、驱动板、FPC 引出方向；否则**真实前脸开窗与控件位置不能出加工图**。
4. 实际挂件厚／最大轮廓、金属扣、平放/浅槽取放轨迹，PN7160 两副读卡天线的线圈方向、连接器／线缆和金属禁区；否则**右后固定座无法冻结**。
5. 电池和主控 S31 成品候选的保护／热／天线／线束／维修包络；S3 试验板不得直接代入成品板面积。

**本阶段可交付**：上述候选尺寸／来源／不确定性登记表、同一坐标系的两条声学路线占位规则、初始分件责任、外包 RFQ 输入缺口和风险处置路径。**尚未交付**：尺寸完整的 CAD 总装、制造 STEP/STL/3MF、工厂有效报价、材料样板、声学/NFC/转动验证。没有相关资料时采用 UNKNOWN，不推算已装入。

**L2 → L3 的放行条件**：有可追溯的准确关键模块尺寸与连接器/运动/手部净空、至少 Q/V 两套带真实净音腔口径的空间结果；如果右后卡座与旋转或音腔发生冲突，必须提交结构替代并保留可选性。之后再做 1:1 空壳／分件模型和可用于外包询价的工程资料，不能只凭生图及虚构 W/D/H 下单。
