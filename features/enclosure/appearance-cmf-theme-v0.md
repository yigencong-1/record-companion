## 1. 目标与取舍基线

1. **用户已表达**：优先把视觉居中的方案 A 深化成好看的外壳；本来有生肖生日礼物主题设想，但当前可先做适合日常使用的**通用外表**；材料与布局解释今后应有**与文本紧邻的生图效果图**，不用难懂的简化线框代替外观表达。未选定最终外观、生肖、准确颜色、控件布局或制造路线。
2. **推荐主外观方向 G1（未冻结）**：奶油白／暖白哑光圆角壳＋深胡桃木视觉顶板＋黑色透声网布＋柔和暖白盘下固定光圈＋少量现成金属质感控件。外观定位是温润、克制、可长期摆放的桌面音乐播放器，不堆砌礼物主题装饰。
3. **视觉布局维持**：横向一体式、水平大盘轴心优先对齐整机横向视觉中线、左右前向出声位置对称、前置墨水屏优先中置；右后静止小卡展示区域只是 L1 候选，不被渲染图锁死；控件数量／类型／映射按 D070 保持可调整。
4. **重要限制**：音质／性价比两条路线同条件验证（D064）；若声学净腔、转动轴承、NFC 读区、真实屏幕包络与外观冲突，要回到结构／器件联合审阅，**不得直接压缩音腔**以复刻渲染体量。
5. **设计思路**：用设计良好的分件接缝取代很难稳定手工完成的全机无缝整体壳。建议顶板与外框之间保留连续窄缝／阴影线；可见拼缝应规律、对称、易清洁，螺钉优先安排在可拆面／底面。实际缝隙数值须依据加工公差和试样确定。

## 2. CMF（颜色／材料／工艺）候选

| 显示部分 | 第一轮可制作建议（不等于批准） | 关键检查与故障风险 |
|---|---|---|
| 暖白圆角外饰框和前板 | 小批 FDM 3D 打印成多件，可分别测试 PETG／其他合适耗材；去支撑、填补明显层纹、打磨、相容底漆和奶油白低光面漆；也可比较外包喷涂 | 单件打印能力、翘曲、上下拼缝一致性、漆膜附着与耐磨；喷涂须有合适安全防护/通风，底漆和喷漆需对实际树脂做附着样片 |
| 视觉木纹顶板 | 激光切割**平整**亚克力基板＋胡桃木纹装饰膜；备选为真实薄木皮／其他可加工平板，尚不指定哪种品牌、膜或实际厚度 | 平面贴合、气泡、热／湿环境下边缘起翘、切口贴边；木纹膜是饰面，**不承担轴承和电机支撑** |
| 黑色扬声器正面 | 两侧各一套可拆格栅环＋专用透声布；后方为独立声学模块，格栅及单元位置对齐 | 网布平整度、松弛与积灰、格栅遮挡、同响度和频响对照；禁止用任意普通密织布直接代替透声材料且宣称不影响音质 |
| 大唱片与中心件 | 轻质装饰唱片／承载盘、独立轴承和真实轴向约束，先验证可拆安装；表面可采用深色细纹装饰，真实沟槽不是必须 | 盘质量／重心／跳动、电机噪声／振动、停机保持；图片上的黑胶外观不代表音频由唱针读取 |
| 盘下暖白光圈 | 固定在机架上的 LED、可拆环槽、乳白导光／扩散窗和遮光边；与大盘保持经过验证的动静间隙 | 光斑、漏光、LED 可见颗粒、温升、维护、能耗和盘跳动；不因效果图连续光带假定灯数或均匀度 |
| 墨水屏窗口 | 真实屏幕及其禁压区域＋独立可拆遮边／前框，机身前面板保留完整 FPC 与驱动板路径 | 旧参考 2.9 英寸 296×128 **不等于**图片里的宽屏实物；屏幕型号、比例与菜单体验仍需选择 |
| 实体控件 | 先用现成有质感旋钮／按钮进行触感台架；装在小块可更换控制子面板中，后续再定布局 | 不把渲染图的“一个旋钮＋一个按钮”误写为正式控件数量；控件行程、手指距离与离线菜单能力联测 |
| 底部及维护背盖 | 独立可拆骨架盖、脚垫、实际散热与 USB／存储／恢复通路；装饰壳不承担核心转盘承重 | 拆电池和主板无需破坏喷涂壳／音腔密封；外部插线与工具空间、装配顺序需模拟和实物验证 |

## 3. 分件、骨架和维护的建议拓扑

| 子组件 | 功能与推荐接口 | 不可违反的原则 |
|---|---|---|
| E0 中央承力底骨架 | 固定前后／上下壳、转盘独立承载板、电子／电池支架及维护盖定位面 | 允许拆装；打印壳表面不直接承轴；刚性和隔振均待验证 |
| E1 左声学模块 | 单元＋完整密闭音腔＋前格栅环；模块单独拆换 | 声学密封边界与 E0 电池、电机、NFC 不连通 |
| E2 右声学模块 | 与 E1 对称、相同测量口径 | 左右音腔净容积和实际单元对照数据不能被外观纹理遮蔽 |
| E3 顶部装饰板 | 平整亚克力基板及胡桃木膜，预留盘扫掠、动静间隙及可换卡座区域 | 顶板不是轴承承重板，也不是音腔开孔通道 |
| E4 旋转与固定光环 | 运动安装板独立固定于 E0，发光环固定、盘独立旋转 | 防脱与承重、盘跳动、灯槽拆装、低音量机械噪声都需验证 |
| E5 前面外观板 | 屏幕视窗／前框、可换操作子板、可拆网罩区域的连续视觉秩序 | 显示真实模块尺寸与玻璃 FPC 禁压区；控制器数量未选 |
| E6 后盖／底盖 | 外部 Type-C、卡／恢复、PCB／电池的可达维护；后盖主对照、底盖作为备选 | 不以更换电池为由要求先破坏声腔密封或拆下转盘 |
| E7 小挂件座可换接口 | 右后固定座／侧边独立固定座均保留，平放浅座／自然落座槽均保留 | 不随大盘动、不破坏声学腔、读卡平面按 NFC 测试重核，挂扣金属离线圈需实测 |

建议的**分件顺序**：先完成 E0＋E1/E2 的占位与音腔边界，再确认 E4 的轴向叠层，之后叠加 E3/E5 的外观板，最后加入 E6/E7 的维护和 NFC 取放约束。真实装配顺序应待候选器件与接线包络到齐后重做。

## 4. 个性化生肖主题：同一台机器，替换局部

**用户已提出作为生日礼物的生肖主题方向，但尚未说明生肖、收礼人专属文案和造型偏好。** 本阶段只设计一个可替换的“视觉主题层”，不自作主张指定生肖，也不新增硬件生日模式。

| 位置 | 提案 | 对原决定的影响 |
|---|---|---|
| 右后静止展示区域周围的**非 NFC 小徽章/装饰片** | 采用可更换木色线描、低饱和印章纹样或非金属浅浮雕，优先位置在挂件座装饰框外；示意图出现的小猫摆件仅是 AI 创意，不是产品配置 | 不改变八张物理 NFC 卡，不遮挡读卡线圈，不把金属纪念牌放在天线工作区 |
| 墨水屏待机背景／普通主题页 | 可选单色生肖插画与简短文案，先测实际屏显效果与刷新 | 不自动增加生日菜单入口；不改变 A/B/C 播放逻辑；特殊生日内容仍按现有单入口决策 |
| 局部可换刻字铭牌／外包装 | 可选姓名／日期／祝福，外壳本体保留通用版的简洁正面 | 不必须刻在喷涂主壳上，防止一次定制后无法变更 |
| **原生日 0 卡** | **保持 D057/D065：近圆形蛋糕外轮廓，背面仅“生日快乐”四字** | 不用生肖图案直接替换生日卡的已确认轮廓／背面文字；仍只有一张生日卡和一个菜单入口 |

三个可视化审阅候选（**非新卡、不新增SKU**）：
- Z1 **温润线描**：浅木色／暖米色非金属主题徽章＋单色线描待机画面，和 G1 主体最一致；建议优先审阅。
- Z2 **克制印章**：仅在局部可换插片或屏幕主题增加一点朱红／棕红；勿将红色扩展到扬声器大面积面板。
- Z3 **浅浮雕质感**：非金属树脂／打印饰件做低矮浅浮雕，上色后检验边界、擦碰、耐用与 NFC 影响；成本／加工难度最高。
- 目前任何图中出现的“兔”“龙”“蛇”等都只能是通用演示样例，不构成具体生肖确认。

## 6. 下一轮需要的输入和可由用户选择的事项

- 明确**制作条件**：用户有无 FDM 打印机、打印尺寸限制；激光切割／喷涂是否能小批外包；手工后处理投入意愿。不在已确认前假设有工业喷涂、CNC 或注塑设备。
- 在 L2 时补整机声学单元、盘承载件、墨水屏外框、NFC 天线、挂件厚度、电池封装真实包络；若不能同时装下，按方案 A 视觉居中优先级进行实体调整。
- 外观 G1 奶油白＋胡桃木作为当前**推荐的通用展示基线**，不是用户最终选中的材料决定。G2 可对照暖白＋浅灰顶板；G3 可对照深木纹／低调黄铜点缀。三者都保持相同水平大盘／双声道结构，不能用换颜色掩盖结构问题。
- 生肖只在通用主体和 CMF 样片可行后确定具体生肖及字体／图案、装饰件位置、礼物包装等；不新增正式 D 决定直到用户审阅确认。
