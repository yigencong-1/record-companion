# 灯光与唱片运动专项

对应 F05、F06。灯光和大唱片转动是桌搭体验，不能成为本地播放的单点故障；两者均应可独立关闭。

## 灯光

候选为低数量WS2812灯环/短灯带与漫射材料，必要时用适配电平转换。验证亮度、全关、场景联动、夜间刺眼程度、峰值电流和对音频供电的干扰。网页和本体都应能设置亮度或关闭。

## 转动

大唱片由独立支撑和低速电机驱动，先比较直接联轴和皮带等传动的振动、噪声、启动电流、停机可靠性和维护性。小唱片挂件保持静止识别，挂扣与运动件保持明确间隙。暂停时是否同步停转、播放恢复方式和转速待实测；夜间建议停转。

## 通过条件

- 灯光低亮和全关可用，夜间无直视刺眼灯珠。
- 电机可可靠启动和停止，停机后仍能正常播放音乐。
- 灯光和运动同时运行时不引入明显底噪、破音、重启或过热。
- 低音量试听时机械声不盖过人声；结构和电机变化后重测声音。
