# 设备管理网页入口

当前没有网页源码或框架定稿。网页运行在设备AP或同一局域网中，提供播放/暂停、切歌、音量、灯光、歌曲上传、歌单和唱片绑定、事件/静态图片管理、网络配置和保存反馈；不以互联网为前提。

完整开发与测试工程先留本机；公开源码按[模块发布条件](../CONTRIBUTING.md#模块工程发布条件)提供已验证操作的必要文件、依赖与证据。界面预览不代表设备联调通过，模拟数据和实机结果分别说明。

本体离线覆盖基本全部功能，网页是另一个入口；网页与本体显示同一播放状态。接口契约需说明格式、容量、上传中断、失败反馈、重启保存和当前歌曲删除规则。设备端接口与内容保存归 [firmware](../firmware/README.md)。真实Wi-Fi密码、服务密钥和其他凭据不进入源码或公开记录。
