# 设备管理网页入口

当前没有网页代码或已确定的前端框架。本目录用于设备AP或同一局域网中的手机管理网页，职责依据[功能规格](../docs/function-spec.md)及后续操作审阅落实。

已确认范围包括音乐控制、灯光设置、歌曲上传、唱片绑定和AP配网。本体离线操作覆盖基本全部功能，网页提供另一个控制和管理入口；AI留到后续扩展。日常显示包及放片即播、取走暂停和换片播放已确认，网页与本体显示同一播放状态。歌单、容量、保存反馈、失败提示和状态同步需形成真实接口契约，生日细则、事件/图片操作及内容管理规则仍待审阅。

网页源码保存在本目录，设备端接口与内容保存归[固件](../firmware/README.md)。使用何种工具、如何生成和打包进固件，待平台和功能比较后记录真实构建步骤。设备管理网页的使用不以互联网连接为前提。

验证包括手机可读性、连接入口、上传中断、保存反馈、状态一致和断网表现。真实Wi-Fi密码、服务密钥及其他凭据不进入源码或公开记录，遵守[项目工作约定](../AGENTS.md#公开提交与本地信息)。
