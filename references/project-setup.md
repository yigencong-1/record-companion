## 自检与验证边界

使用前先运行技能的 `scripts/sw_preflight.py`；按任务需要运行 `scripts/cad_studio.py doctor`。具体解释器由本机记录指定，公开命令示例以 `python` 代指该解释器，不代表任意系统 Python 均可使用。

接入验证在独立临时目录创建独立测试零件，核验建模、原生 `SLDPRT` 保存及 `STL` 导出。保留已有文档和模型，仅处理本轮登记的测试文档；正式产品模型由对应结构实现任务维护，完整工程先留本机，通过相关验证后按[模块发布条件](../CONTRIBUTING.md#模块工程发布条件)整理到 `mechanical/`。

来源包的历史测试不能作为本项目的验证结果。自检、连接成功、文件保存和模型几何有效性分别核验；测试零件通过也不代表产品结构、装配或打印验收通过。当前接入范围不扩大到装配、工程图、仿真等高级能力，实际使用时再按技能能力清单和任务要求验证。
