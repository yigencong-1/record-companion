## 技能边界

全局浏览、PDF、网页设计和可视化技能按真实任务调用；项目级技能只有在平台、工具链和依赖确认后才在协作者本机采用，公开仓库只记录来源、版本和许可。当前未选OLED、KK_OLED、KK_UI或STM32CubeMX2，也没有安装领域技能。

参考资料库按只读方式查阅。公开仓库不记录本机资料库路径；复制内容必须保留公开来源、版本和许可。
