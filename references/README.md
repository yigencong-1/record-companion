## 技能边界

全局浏览、PDF、网页设计和可视化技能按真实任务调用；项目级技能在协作者本机按实际工具链采用，公开仓库只记录来源、版本和许可。当前未选OLED、KK_OLED、KK_UI或STM32CubeMX2。

SolidWorks 自动化技能采用项目级本机快照，保留来源包及本地接口修正，通过 Python COM 调用，不配置 MCP、不安装全局 Skill。范围和验证边界见 [project-setup.md](project-setup.md)，技能本体位于忽略的 `.agents/`。

嘉立创EDA采用官方easyeda-api项目级快照，通过官方CLI/API操作；已完成项目发现与直接脚本连接查询，尚未验证本项目绘图。普通在线窗口的依赖和官方网关按需启用，不配置MCP或全局Skill；公开来源、版本及边界同见[工具接入记录](project-setup.md)。

参考资料库按只读方式查阅。公开仓库不记录本机资料库路径；复制内容必须保留公开来源、版本和许可。
