# 整机验收与证据索引

当前只有规划、公开资料核查和概念图。尚无固件编译/烧录、实物接线、识别、音质、充电、温升或续航的通过结果。T编号是建议验收计划；V编号保留历史产物的追溯，不代表整机已通过测试。

## 每轮验证记录格式

| 记录项 | 必须说明的内容 |
|---|---|
| 日期、目标与范围 | 所处阶段、对应F/T编号及本轮要验证的问题 |
| 可复现条件 | 准确板卡/模块/结构版本、接线与供电、固件提交、工具和操作 |
| 结果与证据 | 预期行为、实际观察、必要数据/图片及证据文件位置 |
| 结论与下一步 | 已通过项、尚未验证项、失败现象和受影响的复测范围 |

概念图、模拟、静态检查、编译、烧录、总线观测、实物功能和使用体验分别标明。公开记录保存准确技术条件与脱敏结果；个人库存、订单、私人素材、本机路径和会话过程不写入本文件。实际验证文件随对应工程保存，这里引用版本和结论，不重复整份日志。

## 整机验收计划

以下计划全部尚未执行；具体次数、时长和量化目标仍需专项审阅。原型、集成板与成品分别记录板版号、固件版本、接线、供电和受影响的功能。

| 编号 | 范围 | 建议验证内容 |
|---|---|---|
| T01 | F01、F03 | 用实际本地素材验证WAV、MP3及最终格式；左右测试音映射正确；断网、无手机持续连接播放30分钟，记录断音、重启和本体控制。 |
| T02 | F02、F10 | 三类常规唱片与一张生日唱片分别绑定；各取放20次，核对放片即播、取走暂停、换片播放、不重复触发、未绑定反馈；开机已放片先识别并等待按播放，随后正常取放规则仍有效；短暂漏读不误停，无唱片的本体/网页播放不因未读到身份而暂停。 |
| T03 | F03、F04 | 用可按压旋钮、播放/暂停键和返回键，断网完成已审阅的音乐、歌单、绑定、生日、灯光、转动和显示操作；检查中文曲名、刷新并发、时间保持和低光可读性。 |
| T04 | F07、F11 | 网页控制与本体状态一致；上传完成后重启，歌曲、绑定和设置仍可用；中断上传不破坏旧内容。 |
| T05 | F08 | 正确/错误网络配置、重试和断网恢复；设备AP管理入口可用；公开证据不保存网络密码。 |
| T06 | F09 | 预期负载下记录Type-C切换、同时使用和充电、充满结束、低电行为、输入限制、容量、平均/峰值功耗和温升。 |
| T07 | F05、F06 | 灯光低亮/全关、可靠停转；比较灯光和电机对声音、供电、功耗和机械噪声的影响。 |
| T08 | F10 | 一张生日唱片和一个菜单入口的配置、进入、播放和退出；共用内容时核对两入口一致。 |
| T09 | F12、F13 | 仅在选择纳入天气或AI后制定；验证价值、网络条件、断网反馈、响应、费用和音乐恢复。 |
| T10 | F14 | 核对固件更新/烧录及扩展接口用途、引脚、电平、供电、资源和成品维护可达性；验证首次烧录、后续更新及应用无法正常启动时的恢复烧录，记录擦除范围和内容影响；未接扩展时核心功能正常。 |
| T11 | F15、F16 | 断网时查看/设置事件和切换已导入图片；检查时间边界、重启保存、刷新和音乐并发。 |
| T12 | F17 | 仅在选入离线语音后制定；分别测试静音和听歌时的指令、误触发、功耗，并与AI问答分开验收。 |

结构、音腔、挂件、固定、装配和维护按对应专项验证；成品材料或布局变化后重测声音、机械噪声、识别、温升及受影响的体验。验收结论须对应实际装配版本。
