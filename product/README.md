# 整机规划

本目录负责产品范围、跨功能目标和整机验收。单功能的参数与试验方案放在 [`features/`](../features/)；实际工程分别放在固件、硬件、网页和结构目录。

## 已确认产品

本体是一套通用本地音乐播放器、唱片桌搭和唱片挂件。它可以离线播放本地音乐，以前置屏与灯光提供日常桌搭体验，评估左右扬声器，并希望实现唱片转动；无唱片时仍能从本体或网页播放。小唱片用于启动绑定内容，也可以挂在书包上；无源身份载体是推荐路线，识别和存储方式尚未选定。首批保留邓紫棋、汪苏泷和通用三类常规唱片，另只保留一张生日唱片和一个生日菜单入口。

## 已确认操作规则

- 唱片与本体、网页是并列播放入口。
- 放入已绑定唱片后自动播放绑定内容；取走唱片暂停；换片播放新绑定内容；同一张持续在位不重复启动。
- 无唱片时，本体或网页仍可开始播放。未绑定或内容缺失时应给出状态反馈，具体错误呈现待细化。
- 日常显示采用时间/日期、播放器状态、事件页面和静态图片切换，离线可用；AI留到后续扩展。
- 本体离线操作覆盖基本全部首版功能；网页提供另一个控制和内容管理入口。

## 跨功能目标

音质不能因为追求小体量而被静默牺牲。扬声器、音腔、功放、供电、机械噪声和成品材料要一起试听；整体外形尽量紧凑，但厘米数由实物模块和装配路径反推。电池支持Type-C边充边用，续航目标为尽量长，必须通过平均/峰值功耗和完整放电测试确定。所有候选器件先比较性能、价格、尺寸、功耗、软件与供货证据，再形成推荐。
