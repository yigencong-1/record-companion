# 整机规划

本目录负责产品范围、跨功能目标和整机验收。单功能的参数与试验方案放在 [`features/`](../features/)；实际工程分别放在固件、硬件、网页和结构目录。

## 已确认产品

本体是一套通用本地音乐播放器、唱片桌搭和唱片挂件。它可以离线播放本地音乐，以前置屏与灯光提供日常桌搭体验，评估左右扬声器，并希望实现唱片转动；无唱片时仍能从本体或网页播放。大唱片确定平放，小挂件比较浅座与无需扣紧的插槽。挂件也可挂在书包上，采用无电池的NFC或类似电磁感应技术，按独立身份编号关联内容；具体器件、编号与内容绑定的保存方式仍待评审。

首批共八张以圆形为基础的卡：邓紫棋、汪苏泷各一张，编号1–5的通用小唱片各一张，以及编号0的生日卡一张。按D065，歌手卡图案后续由用户设计，通用卡不使用明显大数字；生日卡采用近圆形蛋糕轮廓，背面仅“生日快乐”。不同卡片可以采用不同材质，多个完整外壳方案并行比较；两张歌手卡和生日卡重点关注外观与耐用性。生日仍只有一张卡和一个菜单入口。

阶段主控依D063确定为S3模块验证、S31成品主线；准确板型、内存和成品芯片或模组配置尚未冻结。声音依D064并行验证音质与性价比两条路线，主要听距约1米，最终音频器件与费用由可比较证据收敛。

## 已确认操作规则

- 唱片与本体、网页是并列播放入口。
- 按D066–D069，A单曲点播取走继续；B驻留模式确认取走后退出并停止清空其播放任务；C锁存模式取走后继续；B/C单曲/歌单循环。持续在位不重复触发。
- 有效新A或本体/网页主动选择其他歌曲时，先完整退出原B/C再播放；音量调整、暂停及模式内切歌不退出。手动退出后需真正取走再放回才能自动重启B/C。
- NFC标签仅提供独立电子数字身份；本体根据身份决定ABC类型和目标。
- 开机已有唱片先识别，等待显式启动；正常运行新放片才自动执行ABC。启动按键尚待选择。
- 无唱片时，本体或网页仍可开始播放。未绑定或内容缺失时应给出状态反馈，具体错误呈现待细化。
- 日常显示采用时间/日期、播放器状态、事件页面和静态图片切换，离线可用；AI留到后续扩展。
- 本体离线操作覆盖基本全部首版功能；网页提供另一个控制和内容管理入口。
- 可按压旋钮与播放/暂停、返回键仅为当前交互概念；实体控件数量、种类和功能均可继续调整。
- 网页上传新歌曲时保持当前音乐播放，允许上传变慢；能否无断音须在原型并发条件下验证。

### RC-06内容管理规划（待审阅）

建议稳定区分电子UID、逻辑卡、绑定、歌曲Track ID、歌单Playlist ID和模式目标，避免重命名/上传/保存造成唱片错播。网页与本体共用设备端统一命令及修订号；已确认停止音乐不退出B/C，歌单修改应用时机、在位重绑、被引用曲目删除与显式重新播放起点尚待用户决定。曲库、歌单与绑定在离线时也应可进行基本管理，具体物理按键与本地菜单层级未冻结。详见[共享接口](interfaces.md#rc-06--曲库歌单绑定与统一控制的数据契约2026-10-09)和[实施规划](plan.md#rc-06--曲库歌单身份绑定与本体网页统一控制2026-10-09规划草案)。

## 跨功能目标

音质不能因为追求小体量而被静默牺牲。扬声器、音腔、功放、供电、机械噪声和成品材料要一起试听；整体外形尽量紧凑，但厘米数由实物模块和装配路径反推。电池支持Type-C边充边用，续航目标为尽量长，必须通过平均/峰值功耗和完整放电测试确定。所有候选器件先比较性能、价格、尺寸、功耗、软件与供货证据，再形成推荐。

关系图、共享总线、电源、空间和状态约束见 [interfaces.md](interfaces.md)，分阶段项目计划和实施流程见 [plan.md](plan.md)，整机验收与公开验证边界见 [validation.md](validation.md)。
