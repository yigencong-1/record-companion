# 固件工程入口

本机S3音频板基线已固定ESP-IDF v5.5.2和组件依赖并编译通过，尚未烧录或完成实物播放；工程暂留本机，不作为已验证模块发布。成品SDK及集成固件未定。固件应负责本地播放、内容保存、唱片状态、屏幕、灯光/运动控制、本体菜单和网络配合；管理网页源码归 [web](../web/README.md)。

RC-08纯软件行为控制器与测试工程尚未运行；实施顺序、复跑命令与证据要求见[任务清单](../TASKS.md)。完整试验工程先留本机，实际运行的模拟证据与硬件模块实测分开记录，发布遵循[模块发布条件](../CONTRIBUTING.md#模块工程发布条件)。

阶段平台按D063先S3、成品以S31为主。[候选资源分配](../features/platform/resource-allocation.md)已完成，测试板的实际配置和固定依赖在实现对话中核对；主控选型对话不承担测试。原型实现明确板级引脚和外设配置，参考GPIO表不能直接套到兼容板；迁移重核编译目标、解码组件、GPIO/I2S/SD、DMA/缓存、USB恢复及并发，不沿用S3二进制。详细基线和重验清单见[主控专项](../features/platform/README.md#s3验证到s31成品主线)。

建议先建立音频板SD读歌、解码出声、音量/按键及RTC基线，再加入网页上传并发；通用S3板外接墨水屏、识别和其他模块可并行验证。板载单声道播放不计为左右声道或两条声音路线通过，板载充电能力不计为整机边充边用通过。

完整测试工程与在途实现按[模块发布条件](../CONTRIBUTING.md#模块工程发布条件)留本机；公开原型程序随真实平台放入 `firmware/prototypes/`，通过验证的集成工程放入 `firmware/product/`。每个发布模块包含必要源码、准确板卡或PCB版号、依赖和许可、接线与供电、构建/烧录步骤、对应F/T编号及实物证据。凭据和本地网络配置永不进入源码。
