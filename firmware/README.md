# 固件工程入口

当前没有SDK定稿、固件源码或可执行构建入口。固件应负责本地播放、内容保存、唱片状态、屏幕、灯光/运动控制、本体菜单和网络配合；管理网页源码归 [web](../web/README.md)。

当前尚无可运行固件或模拟器；RC-08纯软件行为控制器与测试工程的实施顺序、需提交的命令/日志及准入条件见[活动任务清单](../TASKS.md)。此处不会仅为了补齐文件结构而虚构`CMakeLists.txt`、`sdkconfig`或通过记录。

阶段平台按D063先S3、成品以S31为主，准确原型板与固定依赖仍待审阅。原型实现明确板级引脚和外设配置；迁移重核编译目标、解码组件、GPIO/I2S/SD、DMA/缓存、USB恢复及并发，不沿用S3二进制。详细基线和重验清单见[主控专项](../features/platform/README.md#s3验证到s31成品主线)。

原型程序随真实平台放入 `firmware/prototypes/`，集成工程放入 `firmware/product/`。每个工程说明准确板卡或PCB版号、依赖版本、接线和供电、构建/烧录步骤、对应F/T编号及实际证据。凭据和本地网络配置永不进入源码。
