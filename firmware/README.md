# 固件工程入口

当前尚无固件源码、SDK定稿或可执行构建入口。按[功能规格](../docs/function-spec.md)及[开发流程](../docs/development-process.md)先验证模块，再做集成固件。

原型程序随实际实现放入prototypes/下的模块目录，集成工程放入product/；目录在有真实工程时创建。每个工程说明准确板卡或PCB版号、依赖版本、接线与供电、构建/烧录步骤，以及对应功能和测试编号。

固件负责本地播放、设备状态、屏幕和外围控制、网络与内容保存。管理网页源码归[web](../web/README.md)，其接口和打包方式在平台选择后与固件共同落实。

外部库保留来源、版本和许可；真实网络配置与服务凭据遵守[公开提交规则](../AGENTS.md#公开提交与本地信息)。编译、烧录、软件模拟和实物结果分别写入[验证记录](../docs/verification.md)。
