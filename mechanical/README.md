# 结构与声学工程入口

按D092，当前建模主线为`plan/product-next-stage`按时间最新的[L3整机空间研究](studies/l3-v01/README.md)（`003308b`，2026-10-14），本轮已升级v0.2并回填NFC两板及维护设计；早期SW V3保留作历史参考。已有实体研究模型，尚无制造放行的成品结构。下一步和[hardware](../hardware/README.md)共同补准确器件高度、连接器、线束与固定，按实物收敛声音、电源、运动和维护空间，具体缺项见[结构交接](../features/enclosure/README.md#physical-handoff)。

CAD工具接入已通过独立测试零件的建模、保存重开与STL导出验证，见[工具接入记录](../references/project-setup.md)；该结果不验证产品结构。完整设计与试验工程先留本机，按[模块发布条件](../CONTRIBUTING.md#模块工程发布条件)发布有样件或装配证据的结构模块。

模型和制造文件按结构版号保存，保留可编辑源模型、图纸、打印/加工输出、材料清单、单位和装配顺序，并注明对应PCB版号。概念图、仿真、打印件和真实装配分开记录；改变外壳、材料、布局或隔振后重测受影响的声音、电源、温升和体验项目。
