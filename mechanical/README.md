# 结构与声学工程入口

当前只有外观概念图，没有可制造结构模型。正式结构需和 [hardware](../hardware/README.md) 共同确定音腔、扬声器位置、屏幕开窗、电池固定、识别距离、运动间隙、接口和维护路径。

CAD工具接入已通过独立测试零件的建模、保存重开与STL导出验证，见[工具接入记录](../references/project-setup.md)；该结果不验证产品结构。完整设计与试验工程先留本机，按[模块发布条件](../CONTRIBUTING.md#模块工程发布条件)发布有样件或装配证据的结构模块。

模型和制造文件按结构版号保存，保留可编辑源模型、图纸、打印/加工输出、材料清单、单位和装配顺序，并注明对应PCB版号。概念图、仿真、打印件和真实装配分开记录；改变外壳、材料、布局或隔振后重测受影响的声音、电源、温升和体验项目。
