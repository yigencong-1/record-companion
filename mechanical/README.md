# 结构与声学工程入口

当前没有可制造结构模型。assets/concepts/中的概念图用于外观审阅，未验证制造尺寸、音腔、机构或装配。

依据[功能规格](../docs/function-spec.md)和[硬件工程](../hardware/README.md)，先制作音腔、取放、固定及运动试样，再与成品PCB并行确定外形、接口和装配。原型阶段同步争取更好的声音，保留尺寸、材料、密封、隔振和实际听感记录。

模型与制造文件按真实结构版号创建目录。保留可编辑源模型、必要图纸、打印/加工输出及材料清单，说明工具版本、单位、装配顺序和与PCB版号的对应关系。成品材料按实际声学、触感、耐用和加工收益比较。

仿真、概念模型和真实打印/装配结果分开记录；布局、外壳和材料改变后验证受影响项目。实际结果写入[验证记录](../docs/verification.md)。
